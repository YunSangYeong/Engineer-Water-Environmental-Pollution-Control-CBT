# 수질환경기사 필기 CBT

전기기능사 CBT의 네이비·청록 화면과 학습 기능을 재사용한 비공식 정적 학습 앱입니다.
React 19 + TypeScript + Vite, 서버·로그인·유료 API 없이 브라우저에 기록합니다.

## 실행

Node.js `.node-version`(24.19.0), npm lockfile을 사용합니다.

```sh
npm ci
npm run dev -- --port 5173
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

클라우드의 시스템 Chromium을 쓰려면:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

개발 서버와 preview는 프로세스이며 새 환경에서 다시 시작해야 합니다.
기존 체크아웃에서 작업하고 별도 Git worktree를 만들 필요가 없습니다.

## 기능

- 대시보드, 실전 모의시험, 과목별 랜덤 문제풀이, 오답노트, 북마크, 통계, 문제은행 관리.
- 학습 기준·연도 선택 메뉴 없음. 실전은 답안 선택 후, 랜덤은 즉시 채점 후 Space로 다음 문제 이동. 마지막 시험 문제에서는 자동 제출하지 않습니다.
- 실전 5과목 각 20문항, 총 100문항, 150분. 절대 종료 시각과 답안 저장, 새로고침 복원, 만료 자동 제출, 제출 확인, 중복 제출 방지, 만료 답안 변경 차단.
- 전체 평균 60점 이상과 모든 과목 40점 이상을 함께 판정. 미응답은 오답. 제출 후 전체 해설·과목별 점수·과락·오답 필터·해당 시험 오답 재학습.
- 랜덤 순회 내 ID 중복 방지, 과목 필터, 연속 정답, 이어하기, 재학습 정답 시 오답 해제.
- JSON/CSV 가져오기·양식·검색·페이지·상태 필터·중복 제거·검증 대기·근거 입력 후 로컬 검수 승인·내보내기. 가져오기는 공용 GitHub 은행에 자동 게시되지 않습니다.
- 작은 높이·가로 모드·확대 글자에서도 메뉴 내부 위·아래 스크롤, 하단 백업/초기화와 상단 대시보드 접근.
- 상단 상시 면책 배너 없음. 비공식 표시는 사이드바/푸터, 출처·검수 한계는 문제은행 관리와 문서에 표시. 실제 저장 실패 경고는 유지합니다.

## 공식 규칙 확인 상태와 문제 수

**공식 규칙 대조 미완료**입니다. Q-Net 공식 페이지 요청이 프록시 `403 Forbidden`으로 차단되어 위 규칙은 학습용 잠정 설정입니다. 공식 시험·출제범위·난이도 재현을 보증하지 않습니다. 설정은 `src/profile.ts`에 분리했습니다.

**실제 기본 은행 1,000개, 목표 1,000개 대비 0개 부족**입니다.
기출 0, 복원 0, 자체 제작 1,000. 출제 연도·회차는 모두 null입니다.
계산 20유형 × 10조건 + 신규 26유형 × 30조건 = 980개, 일반 개념 20개입니다.

| 과목 | 등록·내부 검수 | 계산 변형 | 개념 |
|---|---:|---:|---:|
| 수질오염개론 | 260 | 260 | 0 |
| 상하수도계획 | 260 | 260 | 0 |
| 수질오염방지기술 | 230 | 230 | 0 |
| 수질오염공정시험기준 | 230 | 230 | 0 |
| 수질환경관계법규 | 20 | 0 | 20 |

자체 제작은 AI 일반 지식에 따른 작성·내부 해설 검토와 별도 계산 역산 검사를 뜻합니다. 전문가 검수·현행 법령 원문·공식 출제기준 대조는 미실시입니다. 관계법규 20개는 일반 자료 확인·기록·관리 원칙으로, 실제 세부 조문·법정 수치 학습을 대체하지 못합니다. 수량만 채우려고 미검증 법규나 기출을 만들지 않았습니다. 등록 1,000문항 수량은 충족했지만 공식 대조·전문가 검수는 미완료입니다.

동일 유형의 숫자 변형이 의미상 반복됩니다. 모의시험에서는 family별 하나를 우선 선정하고 과목별 20개가 부족하면 나머지 고유 ID로 보충합니다. 현재 계산형 과목의 유형은 12·12·11·11개로 한 시험의 과목별 20문항보다 적어 유형 반복이 발생하며, 실제 시험의 지식 범위를 충분히 다루지 못합니다.

자세한 출처·이용 조건·검수 범위·재현 절차는 [SOURCES.md](docs/SOURCES.md), 실제 검증·배포 상태는 [VALIDATION.md](docs/VALIDATION.md)를 보세요.

## 저장과 개인정보

고유 키 `water-environmental-engineer-cbt:v1`을 사용합니다. 같은 GitHub Pages origin의 다른 자격증 기록과 분리합니다. 최근 응답 5,000개·시험 30회를 보관하고 통계는 그 범위를 집계합니다. 현재 시험·랜덤 세션·오답·북마크·로컬 문항도 저장합니다.

JSON 백업 내보내기와 확인 후 초기화를 제공합니다. 백업을 되가져오는 UI는 없습니다. 손상된 저장 원본은 자동 덮어쓰지 않으며 임시 학습과 원본 백업을 안내합니다. 시크릿/iframe/저장 제한, 다른 기기·origin의 기록 분리, 기기 시계 변경에 따른 타이머 한계가 있습니다.
