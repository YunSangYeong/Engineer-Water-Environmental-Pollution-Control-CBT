# 시험 규칙·자료 출처 확인 (2026-10-31)

## 공식 시험 규칙

대상: 수질환경기사 필기. Q-Net 종목정보 후보 URL:
https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=1662

실제 요청: Python urllib.request.urlopen, HTTPS 검증 유지.
실제 결과: `URLError: Tunnel connection failed: 403 Forbidden`.
공식 본문·첨부 출제기준·기출 원문·재배포 약관을 읽지 못했다.
이 URL은 확인을 시도한 위치이며 열람·검증 완료의 증거가 아니다.
EPA 수처리 자료 https://www.epa.gov/water-research/water-treatment-and-analysis 역시 같은 403으로 열람하지 못했다. 인용 근거로 사용하지 않는다.

`src/profile.ts`의 아래 값은 일반 지식에 따른 **학습용 잠정 설정**이며 최신 공식 검증 완료로 표시하지 않는다:

- 수질오염개론, 상하수도계획, 수질오염방지기술, 수질오염공정시험기준, 수질환경관계법규.
- 과목별 20문항, 총 100문항, 4지선다, 150분.
- 과목별 만점 100점(각 문항 5점), 전 과목 평균 60점 이상, 과목별 40점 이상.
- 미응답은 오답. 판정은 반올림 전 비율을 이용한다.
- 앱의 무작위 추출·난이도·family 보충은 학습용 정책이다. 실제 시험 문항 순서·난이도 재현을 보장하지 않는다.

공식 대조 미완료는 문제은행 관리와 이 문서에 표시한다. 상단 상시 면책 배너는 만들지 않는다.

## 기본 문제은행

실제 `src/data/questions.json`: **1,000문항**, 검증 대기 0, 기출 0, 복원 0, 자체 제작 1,000.
목표 1,000 대비 **부족 0문항**. 등록 수량은 충족했으나 공식 대조·전문가 검수는 미완료다.

| 과목 | 실제 등록·내부 검수 | 계산 변형 | 개념 |
|---|---:|---:|---:|
| 수질오염개론 | 260 | 260 | 0 |
| 상하수도계획 | 260 | 260 | 0 |
| 수질오염방지기술 | 230 | 230 | 0 |
| 수질오염공정시험기준 | 230 | 230 | 0 |
| 수질환경관계법규 | 20 | 0 | 20 |
| 합계 | 1,000 | 980 | 20 |

- 계산 기존 20개 family × 10조건 + 신규 26개 family × 30조건 = 980개. 독립 계산 유형은 **46개**다. 조건 변형을 독립 개념이나 기출로 세지 않는다.
- 개념 20개는 관계법규 학습에 필요한 자료 확인·단위·기록·관리 원칙이다. 현행 조문·법정 수치·제재·신고 기한을 검증한 문항이 아니며, 해당 과목의 실제 출제범위를 충분히 다루지 않는다.
- 조건을 이용한 계산과 일반 개념을 AI 일반 지식으로 작성했다. 읽지 못한 교재나 공식 문서를 정답 근거로 인용하지 않는다. 문항의 저장소 링크는 작성 위치다.
- 출제 연도·회차는 모두 null. 원문 기출과 복원문제는 확보·권리 확인이 되지 않아 수록하지 않았다. 민간 문제 사이트의 원문을 복제하지 않았다.
- 자체 작성 자료의 이용 조건: CC BY 4.0, `수질환경기사 CBT contributors` 및 저장소 링크 표시, 변경 표시. 외부 자료의 권리를 이 라이선스가 대신하지 않는다.
- 수치 변형은 조건·단위·공식·대입·결과를 해설에 표시한다. 법정 수치처럼 보일 수 있는 주입량·설계계수는 명시적으로 주어진 연습 조건이다.

## 실제 검수 범위

내부 검수(reviewed)는 생성 후 조건·단위·정답 유일성·해설 문구를 작성 에이전트가 검토하고 별도 계산 경로를 검사했다는 뜻이다.

1. JSON 스키마·ID·정규화 본문과 보기(보기 재배치 포함) 중복을 검사했다.
2. 계산 검증은 생성 코드와 별개인 TypeScript 테스트에서 역산·질량보존식으로 표시된 답을 검증한다. 정답 번호·반올림·동치 숫자 보기 중복을 함께 확인한다.
3. 의미상 중복: 같은 family의 10개는 의도적 조건 변형이며 독립 유형이 아니다. 관계법규 개념은 모두 교육적 관리 원칙이며 세부 법령 지식의 검증을 대체하지 않는다.
4. 내부 해설 검토와 계산 테스트는 **독립 전문가 검수 또는 공식 출제기준 대조가 아니다**. 두 외부 절차는 미실시다.
5. 모의시험은 family당 한 개를 우선 선택한다. 과목별 20개에 부족하면 남은 고유 ID에서 보충하므로 같은 family가 반복될 수 있다. 계산형 과목의 family는 12·12·11·11개로 한 시험의 과목별 20개보다 적어 반복이 발생한다. 실제 시험의 폭과 난이도에는 미달한다.

생성: `python3 scripts/generate_bank.py`. 시드 없이 고정 조건·고정 순서·고정 ID로 재현한다. 재생성 전 사용자 데이터 변경 여부를 확인한다. 개인 로컬 등록은 기본 1,000개에 포함하지 않으며 가져오기는 항상 검증 대기다.
